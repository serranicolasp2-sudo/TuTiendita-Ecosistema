# Fuentes

Las tres son de Google Fonts, bajo la **SIL Open Font License 1.1**, que permite usarlas, servirlas desde el propio dominio y redistribuirlas. Se usa el subconjunto `latin` (cubre el español), descargado de Fontsource.

| Archivo | Familia | Uso |
|---|---|---|
| `bricolage.woff2` | Bricolage Grotesque (variable, pesos 200–800) | Títulos |
| `figtree.woff2` | Figtree (variable, pesos 300–900) | Texto e interfaz |
| `reenie-beanie.woff2` | Reenie Beanie | Las notas escritas a mano |
